# 几何预处理对大 Mamba 的影响——收敛速度与波动性对比

> 实验:Phase H(大Mamba 3.9M,**无**几何) vs Phase I(大Mamba 3.9M,**有**几何 A8)
> 两者均为 fresh start 8000 iter, Phase I env(reward routing 修复后), seed=1
> 唯一变量:是否启用 A8 几何预处理(obs 98→130: +geo3 +sym29)

## 1. 实验配置

| 项 | Phase H(无几何) | Phase I(有几何) |
|---|---|---|
| 网络 | Mamba d=256, 3层, 3.9M | 同左 |
| obs 维度 | 98 | 130(+geo3 +sym29) |
| env/reward | Phase I(routing 修复) | 同左 |
| seed | 1 | 1 |
| checkpoint | 2026-06-21_21-04-14 | 2026-06-22_10-36-42 |

## 2. 收敛速度对比(episode_length,同 iter)

| iter | 无几何(H) | 有几何(I) | 几何优势 |
|---|---|---|---|
| 500 | 48 | 50 | ≈持平 |
| 1000 | 88 | 111 | +23 |
| **1500** | 147 | **287** | **+140 (+95%)** |
| **2000** | 416 | **672** | **+256 (+62%)** |
| 3000 | 872 | 862 | -10(追平) |
| 4000 | 824 | 851 | +27 |
| 5000 | 715 | 637 | -79 |
| 6000 | 840 | 838 | -2 |
| 7000 | 637 | 851 | +215 |
| 8000 | 897 | 853 | -44 |

**结论**:几何让大 Mamba **早期收敛快 60-95%**(iter 1500-2000 领先 140-256 步)。但 iter 3000 后被无几何追平,最终持平甚至略低。

## 3. 收敛波动性(episode_length 的 std,分阶段)

| 阶段 | 无几何 std | 有几何 std | 差 |
|---|---|---|---|
| 早期 0-2000 | 95 | 167 | 几何波动大(快速爬升期的正常波动) |
| 中期 2000-5000 | 121 | **99** | 几何更稳 -18% |
| 晚期 5000-8000 | 76 | **67** | 几何更稳 -12% |

**结论**:中后期有几何波动略小(-12~18%),更稳但不显著。

## 4. terminated_rate 收敛(越低越好)

| iter | 无几何 | 有几何 |
|---|---|---|
| 1000 | 1.000 | 1.000 |
| 2000 | 0.958 | **0.653** |
| 3000 | 0.158 | 0.220 |
| 5000 | 0.372 | 0.667 |
| 8000 | 0.139 | 0.177 |

**结论**:iter 2000 时有几何 terminated 65% vs 无几何 96%——几何让机器人更早学会不摔。后期都收敛到 14-18%。

## 5. 最终质量(model_8000)

| 指标 | 无几何(H) | 有几何(I) | 差 |
|---|---|---|---|
| episode_length | 897 | 853 | -44 |
| terminated_rate | 14% | 18% | +4% |
| reward/mean_ep100 | 254 | 236 | -18 |
| tracking_lin_vel | 1.464 | 1.412 | -0.05 |
| 最后200点 ep_len CV | 0.102 | 0.090 | 几何略稳 |
| 最后200点 reward CV | 0.108 | 0.097 | 几何略稳 |

**结论**:最终质量几何**无优势**,甚至 episode/reward 略低(在大 Mamba 容量充足时,几何预处理反而轻微限制了网络自由度)。

## 6. 综合结论

**几何优化对大 Mamba(3.9M)的影响**:

| 维度 | 优势 | 程度 |
|---|---|---|
| 早期收敛速度 | ✅ 快 60-95% | 显著(iter 1500-2000) |
| 中后期波动性 | ✅ 略稳 -12~18% | 不显著 |
| 早期不摔 | ✅ 更早学稳 | 显著(iter 2000) |
| 最终质量 | ❌ 无优势 | 持平/略低 |

**核心判断**:
1. **几何优化的价值是省训练时间(早期收敛快),不是省参数或提最终质量**
2. 对大 Mamba(3.9M)收益有限——大网络容量够,自己也能收敛,几何只是加速
3. 对小 Mamba(0.73M)收益更明显(之前数据:iter 3850 小Mamba+几何反超大Mamba同期),但小网络最终学不会走是容量硬限,几何救不了

## 7. 对多技能路线的意义

- 几何优化**值得保留**(省训练时间,无副作用)
- 但不是关键瓶颈——真正瓶颈是**网络容量下限(~2M)和 Mamba 架构设计(A11)**
- 几何预处理注入的先验(对称分量、SE3 不变量)主要帮"找解"阶段,不改变"能学到什么"的上限
